# 🧮 Calculadora Web

## 💻 Sobre o Projeto
Este é um projeto de uma **calculadora web** desenvolvida com **JavaScript, HTML e CSS**. A proposta é criar uma interface simples e funcional que permita realizar cálculos matemáticos de forma rápida e prática diretamente no navegador. A calculadora funciona de maneira similar a uma calculadora tradicional, mas com a conveniência de estar disponível online.

## 🚀 Tecnologias Utilizadas
- **Front-end:** HTML, CSS, JavaScript

## 🧩 Funcionalidades
- ✅ Soma, subtração, multiplicação e divisão.
- ✅ Botões de números e operações matemáticas.
- ✅ Funcionalidade de "limpar" (resetar a calculadora).
- ✅ Exibição dinâmica dos resultados à medida que as operações são realizadas.
- ✅ Design simples e responsivo para funcionar bem em diferentes dispositivos.

## 📸 Como Funciona
1. Abra o arquivo **index.html** em qualquer navegador moderno.
2. Você verá a interface da calculadora com botões para números e operações matemáticas.
3. Clique nos botões para inserir números e operações.
4. O resultado será exibido na tela conforme as operações forem realizadas.
5. Clique no botão "AC" para limpar a tela e iniciar uma nova operação.

1. Clone ou baixe o repositório.
2. Abra o arquivo **index.html** diretamente em seu navegador (não é necessário nenhum servidor).
3. Use a calculadora como uma aplicação web normal.
